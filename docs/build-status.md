# RAtouch build status

Verified on 2026-07-21 against the legally supplied Steam 2229840 data in `ref/`. The commercial payload remains local and Git-ignored; see `asset-provenance.md` for the non-payload receipt.

## First-playable result

The first asset-backed vertical slice is working on Apple Silicon macOS and the iPad Simulator.

- The shared native Apple importer accepts MIX selections, folders, and ISOs, validates every archive, and installs them into an atomic Application Support layout from either the iPadOS Files picker or the macOS first-run picker.
- The deterministic manifest preserves the four same-named disc archives as `allied/MAIN.MIX`, `soviet/MAIN.MIX`, `counterstrike/MAIN.MIX`, and `aftermath/MAIN.MIX`.
- Import writes a `provenance.json` receipt with source ID, source filename, mapped path, byte size, SHA-256, and import time.
- SDL2 is the only Apple audio backend. Game sound and VQA audio share one device and can play as simultaneous mixer streams.
- A late-created iOS SDL renderer now refreshes its output dimensions, avoiding a zero-sized black presentation surface.
- First launch presents native setup UI on both platforms and never bundles game assets. The iPad setup is scroll-safe at accessibility text sizes, and both setup and the command palette expose VoiceOver labels; the command tab can persist on either safe-area edge and opens a native Controls sheet with live persisted touch presets plus a full About and license route. Both Apple bundles carry the complete repository license and expose a source link through native UI.
- The iOS target carries an opaque, full-bleed 1024px RAtouch asset catalog and no longer depends on optional ImageMagick discovery to avoid a blank Home-screen icon.
- The native Mac target now builds as `RAtouch.app` with RAtouch bundle metadata, window title, Application Support path, an original vector-derived app icon, standard app/file/view/window/help menus, a persisted 25–200% pointer-speed control, a resizable window, and a native fullscreen toggle.
- Pointer input now maps window points through renderer output and the actual letterboxed presentation rectangle. This aligns clicks and the software cursor on Retina displays and scales raw deltas into game-space before applying the configured sensitivity. Absolute pointer and direct-touch presses that begin in the surrounding letterbox are ignored, while a press that begins in-frame can still release safely after crossing the frame edge; captured relative input remains unchanged.
- Native Mac Quit and SDL window-close events now converge on a single-shot engine-thread preparation hook. An explicit gameplay-session boundary permits `savegame.999` only after scenario selection/loading has completed and blocks menu or partial-load autosaves. A live Command-Q mission pass changed an isolated autosave and completed cleanup with exit code 0.
- Both Apple targets resolve the importer's nested base-disc layout before bootstrap, so `CONQUER.MIX` text and palette data are available without copying commercial files.
- Both Apple targets compile against a `0x01007E46` save-ABI canary; Aftermath-enabled RAtouch writes `0x01007E47`, matching the retained live Simulator autosave header. Accidental gameplay-struct layout changes now fail the Apple build until a migration and release note explicitly update the contract.
- Both Apple settings surfaces now expose sharp/smooth scaling, preserve/fill aspect handling, and independent music/SFX volume. Changes are clamped, delivered on the SDL engine thread, applied live through the renderer or original Red Alert volume setters, and persisted to the existing INI.
