# RAtouch 0.1.2

The iOS SDL window now keeps its own UIKit scene, so connecting an external display or TV no longer moves or resizes the game window. RAtouch's pinned SDL is the Pad ports' SDL 2.32.10 fork at `090b0c5a`.

App version is 0.1.2, build 3. The touch controls are unchanged: the controller drives the cursor, scrolling, clicks and modifiers, and the touch palette appears only through its own button. The iPad release remains an unsigned public alpha, packaged without commercial game data. PadMint continues to link to the downloadable app. Physical TV and controller acceptance on an iPad is still pending.
