# RAtouch 0.1.1

A selection containing an invalid ISO and otherwise complete game files could previously install only the readable files and report success. Import now aborts the complete selection when any ISO fails to extract. Installed data and any previously validated replacement remain intact. The iPad setup screen reports the failed attempt even when previously imported data is still ready. This shared importer fix applies to initial import and replacement on iPad and Mac.

The regression was reproduced against the previous code with locally supplied supported Steam data and the unchanged production size, SHA-256, and MIX validation. With the fix, mixed invalid/valid selections are rejected; installed receipt, saves, and pending replacement are preserved. No private data is included in the test source or release. Run `scripts/test-importer.sh`; the full supported-input checks also require `RATOUCH_TEST_DATA_DIRECTORY` pointing at a private directory containing exactly one `REDALERT.MIX` and one `MAIN1.MIX` from the supported Steam release.

App version is 0.1.1, build 2. The iPad release remains an unsigned public alpha, packaged without commercial game data. PadMint continues to link to the downloadable app. This change does not establish an exact physical-device or Files-provider picker fix.
